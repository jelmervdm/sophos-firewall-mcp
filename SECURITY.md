# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please send an email to the repository maintainer or submit a private security advisory on GitHub.

### When Reporting

Please include as much information as possible:
- Type of issue (e.g., credential exposure, XML injection, memory leak)
- Step-by-step instructions to reproduce the issue
- Affected components
- Suggested fix (if available)

We will respond promptly to acknowledge your report and keep you updated on progress.
